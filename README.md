# essence-lang.org

The community home page for Essence and Conjure.

This is a static site using Bootstrap CSS, with no JavaScript or build step.
Edit `index.html` for content and `assets/site.css` for local styles.
Bootstrap 5.3.3 is vendored in `assets/bootstrap.min.css`, with its MIT
licence in `assets/bootstrap.LICENSE`.

## Preview

Run `python3 -m http.server 8000` from this directory and open
<http://localhost:8000>.

## Hosting

GitHub Pages serves the root of the `main` branch. `CNAME` configures the
custom domain `essence-lang.org`.
